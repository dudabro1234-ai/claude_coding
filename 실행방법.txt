RE100 PPA Simulator — 실행 방법 (이메일 배포판)
================================================

[준비] 최초 한 번만
  1) Python 3.10+ 설치  (https://www.python.org/downloads/, 설치 시 'Add to PATH' 체크)
  2) 명령 프롬프트(cmd)에서:  pip install pandas numpy

[실행]
  방법 A) 이 폴더의 server.py 를 더블클릭
  방법 B) cmd에서 이 폴더로 이동 후:  python server.py
     → 잠시 후 브라우저에 대시보드가 자동으로 열립니다.

[종료] 검은 창에서 Ctrl + C

[사내망 공유] 실행하면 창에 표시되는
  사내망:  http://<내IP>:8700/   주소를 동료에게 알려주면 접속됩니다.
  (처음 실행 시 Windows 방화벽 '허용' 필요)

[실제 데이터] cmd에서 환경변수로 데이터 폴더 지정 후 실행:
  set PPA_DATA_DIR=C:\사내\데이터폴더
  python server.py

* 이 배포판은 이메일 보안정책 때문에 .bat / .js 파일을 제외했습니다.
  (차트 라이브러리는 화면 파일에 내장되어 있어 그대로 동작합니다)
* 상세 안내는 README.md 참고.
