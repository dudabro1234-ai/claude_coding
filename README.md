# RE100 PPA Simulator (웹 대시보드)

회사의 RE100 PPA 의사결정을 돕는 **웹 대시보드**입니다.
기존 CLI 파이썬 코드(Greedy / Check / Site)를 하나의 검증된 엔진으로 통합하고, 그 위에
**① 결과 차트 화면**과 **② 대화형 AI 도우미**를 좌우로 배치했습니다.

- 2026~2050년(25년) **비용 · RE100 조달 · 사업장(IC·CJ·YI) 배분 · 자동 최적화**를 시뮬레이션
- **추가 서버(Tomcat 등) 설치 불필요** — 파이썬 스크립트 자체가 로컬 웹서버
- **완전 오프라인 동작**(폐쇄망 OK) — 차트 라이브러리 동봉, 외부 폰트 CDN 제거(시스템 폰트 사용), 외부 요청 0건. 데이터는 PC 밖으로 나가지 않음
- 사내망 동료가 **IP로 접속** 가능
- 결과표 **CSV 내보내기**(엑셀 호환) 지원 — 추가 패키지 불필요

## 0. 화면 구성 (시뮬레이션 워크스페이스)

```
┌────────────┬──────────────────────────┬───────────────┐
│ 시나리오 패널 │ 결과                      │ AI 도우미      │
│  RE 목표     │  KPI 4종                 │  결과 질문→답변 │
│  옵션 토글    │  발전믹스/RE경로/비용 차트  │  시나리오 변경  │
│  (즉시 재계산)│  사업장 배분 / 자동 최적화  │  제안→확인→재계산│
│  실행/CSV    │  시나리오 비교 표          │               │
│  스냅샷 저장  │  인사이트                 │               │
└────────────┴──────────────────────────┴───────────────┘
상단 탭: [시뮬레이션] [데이터]  ·  우상단 ⚙: 사내 LLM 설정
```

**주요 사용 흐름**
1. 좌측에서 RE 목표/옵션 변경 → 결과 즉시 재계산
2. [자동 최적화] → 신규 계약 자동 탐색 → **[→ 이 포트폴리오로 사업장 배분 실행]** 파이프라인
3. [＋ 현재 시나리오 저장] 으로 스냅샷을 쌓고 **시나리오 비교** 표에서 대안 비교
4. 우측 AI에 질문하거나 시나리오 변경 요청 (제안→확인→재계산)

## 1. 빠른 시작 (Python이 이미 있는 경우)

1. 이 `ppa-dashboard` 폴더를 PC에 둡니다.
2. **`대시보드_실행.bat`** 더블클릭.
3. 잠시 후 브라우저에 대시보드가 자동으로 열립니다. 끝.

종료: 검은 명령창에서 `Ctrl + C` 또는 창 닫기.

> 자동으로 안 열리면 브라우저에 직접 입력: <http://localhost:8700/>

---

## 2. 처음 설치 (Python이 없는 PC) — 차근차근

### 2-1. Python 설치 (처음 한 번만)
1. <https://www.python.org/downloads/> 접속 → **Download Python 3.12** 클릭.
2. 받은 설치 파일 실행 → 첫 화면 맨 아래 **`Add python.exe to PATH` 체크박스를 꼭 켜고** → `Install Now`.
3. 설치 완료.

### 2-2. 필요한 패키지 설치 (처음 한 번만)
1. 시작 메뉴에서 **명령 프롬프트(cmd)** 실행.
2. 아래 명령 입력 후 Enter:
   ```
   pip install pandas numpy
   ```
   (대시보드 서버 자체는 추가 패키지가 필요 없습니다. 엔진 계산에 pandas/numpy만 사용.)

### 2-3. 실행
- `대시보드_실행.bat` 더블클릭. (이후로는 이 단계만 반복하면 됩니다.)

> `.bat`가 `%LOCALAPPDATA%\Programs\Python\Python312\python.exe`를 먼저 찾고, 없으면 PATH의 `python`을 씁니다.
> Python을 다른 위치에 설치했다면 `.bat` 파일을 메모장으로 열어 `set "PY=..."` 경로만 바꾸세요.

## 3. 사내망 동료가 접속하기 (IP 공유)

서버는 모든 네트워크(`0.0.0.0`)에 열려 있어, **같은 사내망 동료가 IP로 접속**할 수 있습니다.
실행하면 명령창에 두 주소가 표시됩니다:

```
  내 PC:    http://localhost:8700/
  사내망:   http://192.168.x.x:8700/   ← 동료에게 알려줄 주소
```

동료는 브라우저에 그 **사내망 주소**를 입력하면 같은 화면을 봅니다. (별도 WAS·설치 불필요)

**주의사항**
- 처음 실행 시 **Windows 방화벽 허용 창**이 뜨면 `허용`(개인/사내 네트워크)을 누르세요. 안 누르면 동료가 접속 못 합니다.
- 서버는 **내 PC 한 대만** 켜두면 되고, 동료는 설치 없이 브라우저로 들어옵니다. (단, 내 PC를 끄면 동료도 못 봅니다.)
- **인증/접근제한은 없습니다.** IP를 아는 사내망 사람은 누구나 봅니다. 기밀 데이터는 신뢰된 사내망에서만 사용하세요.
- 나만 쓰려면: `server.py`의 `("0.0.0.0", port)`를 `("127.0.0.1", port)`로 바꾸면 로컬 전용이 됩니다.

## 4. 실제(사내) 데이터로 바꾸기

기본은 `data/sample/`의 **샘플 데이터**로 동작합니다. 실제 데이터로 바꾸는 방법 (권장 순):

1. **`data/real_data/` 폴더에 넣기 (권장)** — 실제 CSV 4종을 `data/real_data/`에 넣으면
   환경변수 설정 없이 **자동 인식**합니다. (형식은 [`docs/DATA_SPEC.md`](docs/DATA_SPEC.md) 참조)
2. 다른 폴더를 쓰려면 `대시보드_실행.bat`를 메모장으로 열어 아래 줄의 `REM`을 지우고 폴더 경로 입력:
   ```bat
   set "PPA_DATA_DIR=C:\사내\데이터폴더"
   ```
   (환경변수가 `data/real_data`보다 우선)

> **인코딩 자동 판별:** 엑셀에서 그냥 'CSV'로 저장한 파일(CP949)도, 'CSV UTF-8'(BOM 유무 무관)도
> 그대로 로드됩니다. 컬럼명의 BOM·앞뒤 공백도 자동 정리됩니다.

**입력 CSV 4종** (같은 폴더, 2026~2050년 모두 포함)

| 파일 | 내용 |
|------|------|
| `Hourly_Data.csv` | 시간별 발전계수 / SMP (연도별 8,760행) |
| `Annual_Usage.csv` | 연간 사용량 / 피크 / RE 목표 |
| `Annual_PPA.csv` | 발전원별 PPA 단가 |
| `Annual_Rate.csv` | 한전 요금 / EAC 단가 |

> 샘플 데이터를 다시 만들려면: `python tools/generate_sample_data.py`

### 기준정보 시나리오 (선택)

기준정보를 시나리오로 분류해 **최대 2(사용량 base/worst) × 2(PPA단가 고정/변동) × 3(SMP 기본/고가/저가) = 12개 case**를
비교할 수 있습니다. 방법은 데이터 폴더에 다음을 **추가**하는 것뿐입니다 (기존 4종은 그대로):

- `Annual_Usage_worst.csv` — Worst 수요안 (기존 사용량 파일과 같은 컬럼 구조)
- `Annual_PPA.csv`에 `PV_V`, `On_W_V` 등 **연도별 변동 단가 컬럼**
- `Annual_Rate.csv`에 `SMP_H` / `SMP_L` **배수 컬럼**

추가된 시나리오는 대시보드 좌측 "기준정보 시나리오" 드롭다운과 **시나리오 매트릭스**(전 조합 일괄 비교)에
자동으로 나타납니다. 자세한 규칙은 [`docs/DATA_SPEC.md`](docs/DATA_SPEC.md) 4-1절 참조.

> 12개 조합이 채워진 데모 폴더 생성: `python tools/generate_scenario_data.py`
> → `PPA_DATA_DIR=data/sample_scenario` 로 실행

## 5. AI 도우미(사내 LLM) 연결

기본은 **Mock(규칙 기반)** 으로 동작합니다(LLM 없이도 질문/시나리오 변경 흐름 작동).

**가장 쉬운 방법 — 화면에서 설정 (권장)**
1. 대시보드 우측 상단 **⚙ (LLM 설정)** 클릭
2. Base URL(`http://사내LLM주소:포트/v1`) · 모델명 · API 키(있으면) 입력
3. **[🔌 연결 테스트]** → 성공 확인 → **[저장]** (설정은 `llm_config.json`에 저장되어 재시작해도 유지)

IT/LLM 담당자에게 물어볼 것: **"Qwen(또는 GLM)의 OpenAI 호환 endpoint 주소(/v1)와 모델명, API 키 필요 여부"**

환경변수로도 지정 가능(화면 설정보다 우선함):
```bat
set "PPA_LLM_BASE_URL=http://사내LLM주소:포트/v1"
set "PPA_LLM_API_KEY=키없으면-생략"
set "PPA_LLM_MODEL=Qwen2.5-72B-Instruct"
```
- Qwen·GLM은 보통 **OpenAI 호환 API**(`/chat/completions`)로 서빙되므로 코드 수정 없이 연결됩니다.
- 서빙 방식이 다르면 `agent.py`의 `_call_llm` 함수 한 곳만 수정하면 됩니다.
- 상세 절차: [`docs/회사_셋업_가이드.md`](docs/회사_셋업_가이드.md)

## 7. 자주 묻는 문제 (문제 해결)

| 증상 | 해결 |
|------|------|
| `.bat` 실행 시 "Python을 찾을 수 없습니다" | 2-1 Python 설치(특히 **Add to PATH 체크**). 또는 `.bat`의 `set "PY=..."` 경로 수정 |
| `ModuleNotFoundError: pandas` | `pip install pandas numpy` 실행 (2-2) |
| 동료가 IP로 접속이 안 됨 | ① 방화벽 허용했는지 ② 같은 사내망인지 ③ 내 PC가 켜져 있고 `.bat`가 실행 중인지 확인 |
| 한글이 깨져 보임 | `.bat`가 자동 처리(UTF-8). 직접 실행 시 `set PYTHONUTF8=1` 후 `python server.py` |
| "엔진 미연결"이라고 뜸 | `web/index.html`을 **직접 더블클릭하면 안 됨**. 반드시 `.bat`로 실행 |
| 포트 8700이 사용 중 | `python server.py 8701` 처럼 다른 포트로 실행 |
| AI 도우미가 "Mock"으로 표시 | 정상(사내 LLM 미연결 상태). 5번대로 연결하면 사내 LLM 사용 |

## 9. 현재 범위와 다음 단계

**되는 것**
- 결과 차트(run_check) 실시간 계산 — 좌측 시나리오 변경 시 즉시 재계산
- 사업장 배분(run_site) / **자동 최적화(run_greedy)** — SMR·균등 토글 반영, **최적화 결과로 곧바로 사업장 배분 실행(파이프라인)**
- **시나리오 스냅샷 저장 → 비교 표** — 대안 시나리오 간 총비용/RE/EAC 비교
- **CSV 내보내기** — 연간 비용분석 / RE 조달현황 (엑셀 호환)
- AI 도우미: 결과 해석 + 시나리오 변경(제안→확인→재계산). **⚙ 설정 화면에서 사내 LLM 연결·연결 테스트**
- 같은 시나리오 재계산은 서버가 캐시해 즉시 응답
- run_check에 직접 반영: RE 목표(`re_goal_column`), SEC 가동중단(`sec_stop`) / run_greedy에 반영: SMR·균등 옵션

**아직 안 되는 것 (다음 단계 후보)**
- 단가 민감도/요금 인상/신규계약 상한 슬라이더의 엔진 실연동 (엔진 확장 필요)
- 자동 최적화 결과를 사업장 배분(run_site)까지 이어서 실행하는 원클릭 파이프라인
- 사내 LLM 실제 연결 테스트 (Qwen/GLM 엔드포인트 확보 후)
