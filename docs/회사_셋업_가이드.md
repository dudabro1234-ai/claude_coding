# 회사 PC 셋업 가이드 — RE100 PPA Simulator

> 회사(폐쇄망/외부 접속 불가) PC에서 처음 설치할 때 이 순서대로 하면 됩니다.
> 예상 소요: Python이 이미 있으면 **5분**, 없으면 **20분**.

---

## 준비물 체크리스트

- [ ] `ppa-dashboard-email.zip` (이메일로 받았거나 USB로 반입)
- [ ] Python 3.10 이상 — 없으면 **사내 소프트웨어 센터** 또는 IT에 설치 요청
- [ ] (선택) 실제 입력 CSV 4종 — 없으면 샘플 데이터로 우선 시연 가능
- [ ] (선택) 사내 LLM 접속 정보 — AI 도우미용. 없어도 규칙 기반으로 동작

---

## STEP 1. 압축 해제

`ppa-dashboard-email.zip` 우클릭 → **압축 풀기** (윈도우 탐색기로 바로 됨, 비밀번호 없음)
→ `ppa-dashboard` 폴더가 생깁니다. 아무 위치나 괜찮습니다 (예: `D:\PPA\ppa-dashboard`).

## STEP 2. Python 확인 / 설치 (최초 1회)

명령 프롬프트(cmd)에서:
```
python --version
```
- **3.10 이상 나오면** → STEP 3으로
- **없거나 오류면** → 사내 소프트웨어 센터에서 Python 설치 (설치 시 **"Add python.exe to PATH" 체크 필수**).
  폐쇄망이라 python.org 접속이 안 되면 IT에 "Python 3.12 설치" 요청.

## STEP 3. 패키지 설치 (최초 1회)

```
pip install pandas numpy openpyxl
```
- 폐쇄망에서 pip이 외부에 못 나가면, 대부분 **사내 pip 미러**(Nexus/Artifactory)가 있습니다. IT에 물어보세요:
  ```
  pip install pandas numpy openpyxl --index-url http://사내미러주소/simple --trusted-host 사내미러주소
  ```
- 이 두 개면 끝입니다. 대시보드 서버 자체는 파이썬 기본 기능만 씁니다.

## STEP 4. 첫 실행 (샘플 데이터)

`ppa-dashboard` 폴더에서 **`server.py` 더블클릭** (또는 cmd에서 `python server.py`)
→ 검은 창이 뜨고 잠시 후 브라우저에 대시보드가 자동으로 열립니다.

- 처음 실행 시 **Windows 방화벽 창**이 뜨면 → **허용** (동료 접속에 필요)
- 종료: 검은 창에서 `Ctrl + C` 또는 창 닫기
- 매번 더블클릭이 번거로우면, 메모장으로 아래 내용을 `실행.bat`로 저장해 두세요:
  ```bat
  @echo off
  chcp 65001 >nul
  set PYTHONUTF8=1
  cd /d "%~dp0"
  REM 실제 데이터를 쓰려면 아래 줄의 REM을 지우고 경로 지정
  REM set "PPA_DATA_DIR=D:\PPA\실제데이터
  python server.py
  pause
  ```

## STEP 5. 실제 데이터 연결

**방법 A (권장) — `data\real_data` 폴더에 넣기**

1. 프로그램 폴더 안의 `data\real_data` 폴더에(없으면 새로 생성) 실제 CSV 4종
   (`Hourly_Data.csv`, `Annual_Usage.csv`, `Annual_PPA.csv`, `Annual_Rate.csv`)을 넣습니다.
   컬럼 형식은 같은 폴더의 **`docs/DATA_SPEC.md`** 참조 (담당자에게 이 파일을 전달하면 됩니다).
2. 그냥 `python server.py` 실행 — 환경변수 설정 없이 자동 인식되며,
   시작 메시지에 `[데이터] …\data\real_data (실데이터 자동 인식)` 이 표시됩니다.

> 💡 **인코딩·형식 걱정 불필요:** 엑셀에서 그냥 'CSV'로 저장한 파일(CP949)도, 'CSV UTF-8'로 저장한
> 파일(BOM 유무 무관)도, **엑셀 통합문서(.xlsx)** 도 자동 판별해 로드합니다.
> xlsx를 이름만 `.csv`로 저장한 파일까지 내용으로 감지하며(첫 번째 시트 사용),
> 판별이 안 되는 파일만 "엑셀에서 CSV UTF-8로 다시 저장하세요" 오류가 표시됩니다.
> ※ xlsx 입력을 쓰려면 `pip install openpyxl` (STEP 1 설치 목록에 포함)

**방법 B — 다른 폴더를 쓰려면 환경변수 지정**

```
set PPA_DATA_DIR=D:\PPA\실제데이터
python server.py
```
(또는 STEP 4의 `실행.bat`에서 해당 줄 주석 해제. 환경변수가 `data\real_data`보다 우선합니다.)

확인: 대시보드 하단/데이터 탭에서 데이터 폴더 경로가 바뀐 것을 확인.

## STEP 6. 사내 LLM 연결 (AI 도우미)

1. IT/LLM 담당자에게 **이렇게 물어보세요**:
   > "Qwen(또는 GLM) 모델의 **OpenAI 호환 API endpoint 주소**(보통 `http://…:포트/v1`)와 **모델명**, 그리고 **API 키**가 필요한지 알려주세요."
2. 대시보드 우측 상단 **⚙ (LLM 설정)** 클릭 → 받은 정보 3개 입력
3. **[🔌 연결 테스트]** 클릭 → "✓ 연결 성공" 확인 → **[저장]**
4. 상단 배지가 `LLM: 사내 LLM`으로 바뀌면 완료. 이후 우측 AI 도우미가 사내 LLM으로 답합니다.
   (연결 전까지는 규칙 기반 Mock으로 동작 — 시나리오 변경 기능은 그대로 사용 가능)

## STEP 7. 동료에게 공유 (사내망)

서버 실행 창에 표시되는 주소를 알려주면 됩니다:
```
  사내망:   http://192.168.x.x:8700/   ← 이 주소를 동료에게
```
- 동료는 **설치 없이 브라우저만으로** 접속 (내 PC가 켜져 있고 서버가 실행 중일 때)
- 안 되면: ① 방화벽 허용했는지 ② 같은 사내망인지 확인

## 문제 해결

| 증상 | 해결 |
|------|------|
| `python` 명령이 안 먹힘 | Python 설치 시 "Add to PATH" 누락 → 재설치 또는 IT 문의 |
| `ModuleNotFoundError: pandas` | STEP 3 재실행 (사내 미러 옵션 포함) |
| 브라우저가 자동으로 안 열림 | 직접 입력: `http://localhost:8700/` |
| "엔진 연결 실패" 표시 | `web/index.html`을 직접 열었을 때 발생 → 반드시 `server.py`로 실행 |
| 포트 충돌 (8700 사용 중) | `python server.py 8701` 처럼 다른 포트 지정 |
| 동료가 접속 안 됨 | 방화벽 허용 / 같은 망 / 서버 실행 중인지 확인 |
| LLM 연결 실패 | URL 끝 `/v1` 확인, 모델명 정확히, [저장] 후 다시 테스트 |
| 한글 깨짐 | `set PYTHONUTF8=1` 후 실행 (STEP 4의 실행.bat 사용 권장) |

## 화면 사용법 (1분 요약)

- **좌측 패널**: RE 목표·옵션 바꾸면 **즉시 재계산**. [사업장 배분]·[자동 최적화] 실행, CSV 내보내기, 시나리오 스냅샷 저장
- **중앙**: KPI·발전믹스·RE경로·비용 차트. 자동 최적화 후 **[→ 이 포트폴리오로 사업장 배분 실행]** 으로 이어서 실행 가능
- **스냅샷**: 조건 바꿔가며 [＋ 현재 시나리오 저장] → 하단 **시나리오 비교** 표에서 총비용/RE/EAC 비교
- **우측 AI**: 결과 질문("총비용 왜 이래?") / 시나리오 변경 요청("SMR 넣으면?") → 제안 확인 후 재계산
- **데이터 탭**: 입력 CSV 4종의 실데이터 차트와 준비 방법
