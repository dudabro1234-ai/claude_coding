# 수정내역 — 2026-07-09 (기준정보 시나리오 분류)

## 요약

기준정보(입력 데이터)를 시나리오 축으로 분류해 **최대 2×2×3 = 12개 case**를
테스트할 수 있게 확장했다. **기존 입력 4종 CSV는 그대로 실행 가능**하며(하위 호환),
그 경우 결과는 이전 버전과 완전히 동일하다 (회귀 테스트로 보증).

| 축 | 시나리오 | 입력 |
|----|----------|------|
| 사업장 사용량 | base / worst | `Annual_Usage_worst.csv` 파일 추가 (없으면 base만) |
| PPA 단가 | 고정(현행) / 연도별 변동 | `Annual_PPA.csv`에 `PV_V`, `On_W_V` … 컬럼 추가 (없으면 고정만) |
| SMP | 기본안 / 고가 / 저가 | `Annual_Rate.csv`에 `SMP_H` / `SMP_L` 배수 컬럼 추가 (없으면 기본만) |

발전패턴(`Hourly_Data.csv`)은 요청대로 시나리오 공통(단일)이다.

## 변경 파일

### core/config.py
- 시나리오 축 정의 추가: `USAGE_SCENARIOS`, `PPA_PRICE_SCENARIOS`, `SMP_SCENARIOS` + 각 기본값
- `SimulationParams`에 `usage_scenario` / `ppa_scenario` / `smp_scenario` 필드 추가

### core/engine.py
- `DataBundle`을 시나리오 다중 보관 구조로 변경:
  `usage_scenarios{시나리오→연도→행}`, `ppa_scenarios{시나리오→발전원→단가}`, `smp_rate_cols{시나리오→배수컬럼}`
  - 기존 코드 호환용 `bundle.usage` / `bundle.price_dicts` 프로퍼티 유지 (기본 시나리오 별칭)
  - `usage_for(params)` / `prices_for(params)` / `smp_rate_col_for(params)`: 선택 해석 + 없는 시나리오는 안내 메시지와 함께 거부
  - `scenario_options()`: 데이터에 실제 존재하는 시나리오만 반환 (대시보드 노출용)
- `load_data()`: 시나리오 자동 감지 로드
  - `Annual_Usage_{시나리오}.csv` 파일 존재 시 로드
  - `Annual_PPA.csv` 접미사 컬럼(`*_V`) 감지 — **발전원별로 없으면 `*_M` 폴백** (예: 수력/SMR)
  - `Annual_Rate.csv`의 `SMP_H`/`SMP_L` 배수 컬럼 감지
- `cost_company` / `cost_site`: SMP 배수를 `_smp_multiplier(rate_row, params)`로 해석
  (기본안은 컬럼이 없어도 배수 1 — 원본 동작 보존)
- `run_check` / `run_greedy` / `run_site` 경로 전부 `usage_for`/`prices_for` 사용으로 전환

### server.py
- `ENGINE_PARAM_KEYS`에 시나리오 3키 추가 (→ 실행·캐시 키에 자동 반영)
- `/api/meta`: `scenarios`(존재하는 시나리오 목록) + `scenario_defaults` 반환
- **`/api/matrix` 신설**: 존재하는 모든 기준정보 조합을 일괄 계산해 KPI 비교 반환

### web/index.html
- 좌측 패널 "기준정보 시나리오" 섹션: 사용량/PPA단가/SMP 드롭다운 3개
  (데이터에 있는 시나리오만 표시, 단일이면 비활성)
- 시나리오 pill·인사이트 라벨·스냅샷·비교표에 시나리오 태그 반영
- **"시나리오 매트릭스" 카드 신설**: 일괄 계산 → 12개 조합 KPI 표 (최소/최대 표시, "적용" 버튼으로 해당 조합 즉시 선택)
- AI 도우미 제안(`applyParams`)도 시나리오 키 반영

### tools / data / docs
- `tools/generate_scenario_data.py` 신설: `data/sample` → 12개 조합이 채워진 `data/sample_scenario/` 데모 폴더 생성 (기존 샘플은 수정하지 않음)
- `tools/scenario_test.py` 신설: 7개 검증 (하위 호환 회귀 / 시나리오 감지 / 조합 수 / 기본 조합 동일성 / 축별 반영 / 발전원 폴백 / 오류 처리)
- `docs/DATA_SPEC.md`: "4-1. 기준정보 시나리오 확장" 섹션 추가

## 하위 호환 보증

- `data/sample`(기존 4종 CSV)에서 기본 파라미터 실행 결과가 개선 전 엔진과
  **수치 단위로 동일**함을 확인 (25년 총비용 11,556,160.53 백만원, 비용표/RE표 CSV 완전 일치)
- 구버전 payload(시나리오 키 없는 요청)도 그대로 동작 (기본 시나리오로 처리)
- 없는 시나리오 요청 시 명확한 안내: 예) `사용량 시나리오 'worst' 데이터가 없습니다. (가능: ['base'] — Annual_Usage_worst.csv 를 데이터 폴더에 추가하세요)`

## 검증 결과

- `python tools/scenario_test.py` → 7/7 통과
- 서버 E2E: `/api/meta` 시나리오 감지, `/api/run` 조합 실행, `/api/matrix` 12조합 일괄 계산 확인
- 브라우저 E2E(Playwright): 드롭다운 렌더·선택 시 재계산·pill 라벨·매트릭스 12행 표시, JS 오류 없음
