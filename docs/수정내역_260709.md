## 4차: 데이터 탭 빈 화면(실데이터 NaN → 비표준 JSON) 수정

실데이터에 **빈 셀**이 있으면 `/api/inputs` 응답에 `NaN` 토큰이 들어가고,
브라우저 `JSON.parse`가 이를 거부해 **데이터 탭 차트가 전부 빈 화면**이 되던 문제
(시뮬레이션 탭은 정상이라 원인 파악이 어려웠음 — 프런트가 오류를 조용히 삼키고 있었음).

- **`server.py` `_json_safe()`**: 모든 API 응답에서 NaN/Infinity → null 치환 (표준 JSON 보장)
- **`f()` 헬퍼**: NaN/무한대도 0.0으로 (차트 데이터 방어)
- **`api_inputs` 섹션별 독립 처리**: 사용량/PPA/SMP/요금 중 한 섹션이 실패해도
  나머지는 표시하고, 실패 사유를 `warnings`로 내려보냄. SMP 평균은 숫자 강제 변환
  (`pd.to_numeric(errors="coerce")`)으로 문자 혼입 방어.
- **데이터 탭 오류 표시**: 로드 실패·경고를 화면 상단 배너로 표시 (조용한 실패 제거),
  차트도 섹션별 독립 렌더링. 축 눈금 부동소수점 노이즈(110.10000000000002원) 정리.
- **`tools/encoding_test.py` [9]** 추가: 빈 셀 데이터에서 표준 JSON 보장 회귀 테스트.

## 3차: 엑셀(.xlsx/.xls) 입력 지원 — "이름만 .csv인 엑셀 파일"까지 자동 감지

이름만 `.csv`이고 실제로는 엑셀 통합문서로 저장된 파일에서 나던 로드 오류를 해결하고,
아예 `.xlsx` 확장자 그대로도 쓸 수 있게 했다.

- **`read_csv_kr()` 확장**: 파일 첫 바이트(매직 넘버)로 형식을 판별 —
  xlsx(zip)·구형 xls(OLE2)면 확장자와 무관하게 `pd.read_excel`(첫 번째 시트)로 읽음.
  → **xlsx를 이름만 `*.csv`로 저장한 파일도 정상 로드** (사내에서 실제 발생한 케이스).
  openpyxl 미설치 시 `pip install openpyxl` 안내와 함께 실패.
- **`find_input_file()` 신설**: 입력 파일을 `.csv` → `.xlsx` → `.xls` 순으로 탐색.
  `Hourly_Data.xlsx`, `Annual_Usage_worst.xlsx` 처럼 엑셀 확장자 그대로 사용 가능.
- **`server.py`**: real_data 자동 인식·시작 안내·CSV 교체 감지(캐시 서명)가
  xlsx/xls 파일도 인식하도록 수정.
- **의존성**: `requirements-docker.txt`에 `openpyxl` 추가 (requirements.txt에는 기존부터 포함),
  설치 안내(`pip install pandas numpy openpyxl`) 문서 일괄 갱신.
- **`tools/encoding_test.py` 확장**: [6] xlsx 입력(CSV 혼용) [7] 이름만 .csv인 엑셀 파일
  [8] 확장자 폴백 탐색 — 모두 CSV 원본과 계산 결과 동일 확인.

## 2차: 실데이터 로드 실패(인코딩) 해결 + real_data 폴더 자동 인식

사내 실데이터(엑셀 저장본 CP949) 로드가 UTF-8 고정 읽기 때문에 실패하던 문제를 해결했다.

- **`core/engine.py` — `read_csv_kr()` 신설**: 모든 CSV 로드가 UTF-8(BOM 유무 무관) →
  CP949 → EUC-KR 순으로 인코딩을 자동 판별. 컬럼명의 BOM·앞뒤 공백도 일괄 정리.
  판별 실패 시 "엑셀에서 'CSV UTF-8'로 다시 저장" 안내와 함께 실패.
  연간 파일 3종 모두 천단위 콤마(`thousands=","`) 허용으로 통일.
- **`server.py` — `data/real_data/` 자동 인식**: 폴더에 4종 CSV가 있으면 환경변수 없이
  자동 선택 (우선순위 `PPA_DATA_DIR` > `data/real_data` > `data/sample`).
  파일이 일부만 있으면 시작 메시지에서 누락 파일을 안내.
- **`.gitignore`에 `data/real_data/` 추가** — 실데이터가 저장소에 커밋되지 않도록 차단.
- **`tools/encoding_test.py` 신설**: CP949/UTF-8(BOM)/공백 컬럼명 로드 결과 동일성,
  오류 안내 문구, real_data 자동 인식까지 5개 검증.
- `tools/generate_scenario_data.py`도 `read_csv_kr` 사용 (실데이터 폴더 대상 실행 가능).
- 문서 갱신: README / DATA_SPEC(공통 규칙) / 회사_셋업_가이드 STEP 5 / 실행방법.txt

# 1차: 기준정보 시나리오 분류

## 요약

기준정보(입력 데이터)를 시나리오 축으로 분류해 **최대 2×2×3 = 12개 case**를
테스트할 수 있게 확장했다. **기존 입력 4종 CSV는 그대로 실행 가능**하며(하위 호환),
그 경우 결과는 이전 버전과 완전히 동일하다 (회귀 테스트로 보증).

| 축 | 시나리오 | 입력 |
|----|----------|------|
| 사업장 사용량 | base / worst | `Annual_Usage_worst.csv` 파일 추가 (없으면 base만) |
| PPA 단가 | 고정(현행) / 연도별 변동 | `Annual_PPA.csv`에 `PV_V`, `On_W_V` … 컬럼 추가 (없으면 고정만) |
| SMP | 기본안 / 고가 / 저가 | `Annual_Rate.csv`에 `SMP_H` / `SMP_L` 배수 컬럼 추가 (없으면 기본만) |

발전패턴(`Hourly_Data.csv`)은 요청대로 시나리오 공통(단일)이다.

- UI: 자동 최적화 카드에 시작 포트폴리오 선택, 추가 0건 시 사유 문구 표시
- RE 목표 _SEC 시나리오 주석: KPI·달성경로 카드에 "SEC 수전 제외 목표" 표기
